# tests/

Cross-cutting proofs. Tests that belong to one package live next to that package's source; what lives here is the evidence the submission actually rests on.

## Local rules

- **The possible-worlds proof is the headline and it is a blocking CI gate.** For every seed and every reachable state it asserts two things, and clause (b) carries the weight:
  - (a) the set of worlds consistent with `projectForKeeper(s)` has more than one member, and
  - (b) those worlds **disagree about the correct action**.
  That is the exact, checkable, mathematical statement of "you cannot win without your human". Assertion (a) alone proves nothing interesting.
- The mirror runs for `projectForPilot` against the `TACTILE` channel. Symmetric asymmetry, proven both directions.
- **The substring smoke test is not the headline** and must never be described as the proof. Absence of a literal value is not absence of information. It runs on every commit with a documented allow-list, and its limitations are stated in the test file itself.
- **The published bits-per-chamber table is generated by the same code the proof uses.** A hand-written number in the README can drift from the test; a generated one cannot. Never type a bits value by hand.
- **A leak is not a bug, it is a build that is not the game.** These gates are never skipped, never marked `.todo`, and never weakened to go green. Weakening an asymmetry check to make it pass is the one change that is never accepted.
- Where full enumeration of the world space is infeasible, enumerate over the **puzzle-defining parameters** instead and state that scoping honestly in the test file. Silent scoping is how a proof becomes a decoration.
- Playwright covers what unit tests cannot observe: that aborting a controller actually removes tools from `getTools()`, that `toolchange` fires on register **and** abort, that cross-origin tools are visible to the game origin and only to it, and that the final registry of a session is empty. That last one is both a test and the game's ending.
