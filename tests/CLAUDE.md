# tests/

Cross-cutting proofs. Tests that belong to one package live next to that package's source; what lives here is the evidence the submission actually rests on.

## Local rules

- **The possible-worlds proof is the headline and it is a blocking CI gate.** For every seed and every reachable state it asserts two things, and clause (b) carries the weight:
  - (a) the set of worlds consistent with `projectForKeeper(s)` has more than one member, and
  - (b) those worlds **disagree about the correct action**.
  That is the exact, checkable, mathematical statement of "you cannot win without your human". Assertion (a) alone proves nothing interesting.
- The mirror runs for `projectForPilot` against the `TACTILE` channel. Symmetric asymmetry, proven both directions.
- **The substring smoke test is not the headline** and must never be described as the proof. Absence of a literal value is not absence of information. It runs on every commit with a documented allow-list, and its limitations are stated in the test file itself.
- **The published bits-per-chamber table is generated by the same code the proof uses.** A hand-written number in the README can drift from the test; a generated one cannot. Never type a bits value by hand.
- **A leak is not a bug, it is a build that is not the game.** These gates are never skipped, never marked `.todo`, and never weakened to go green. Weakening an asymmetry check to make it pass is the one change that is never accepted.
- Where full enumeration of the world space is infeasible, enumerate over the **puzzle-defining parameters** instead and state that scoping honestly in the test file. Silent scoping is how a proof becomes a decoration.
- **A browser covers what unit tests cannot observe:** that aborting a controller actually removes tools from `getTools()`, that `toolchange` fires on register **and** abort, that cross-origin tools are visible to the game origin and only to it, and that the final registry of a session is empty. That last one is both a test and the game's ending. `cross-origin-delegation.ts` is that file, driven over the DevTools Protocol rather than through Playwright: the protocol arrives with the browser, so the proof has no dependencies at all.
- **A browser proof runs against live servers and is therefore not a `*.test.ts`.** Vitest collects only `*.test.ts`, so nothing here needs guarding against a harness that cannot start three servers. Say in the file how to run it, and record results in the decision log and doc 11 with a date and a browser version.
- **The screenshot tour rides on the browser proof rather than living in a file of its own.** `SHOTS=<dir>` makes `cross-origin-delegation.ts` write a frame at every beat and is a no-op without it, so the assertion run is unchanged. It is bolted there because reaching a late room means solving the rooms before it and those solvers are already in that file. **Wait for the camera before capturing, and keep the wait longer than `WALK_MS + SHOT_MS` in `apps/game/src/render/camera.ts`.** A frame grabbed early is the previous room with the next room's name over it, or the whole building seen from four hundred metres up. Both have happened, once per renderer, and the second one is the more dangerous because it looks like a framing decision rather than a timing bug. If a frame comes back oddly distant, check this number against those two constants before looking at the scene.
- **Look at a renderer change, do not only test it.** Four rendering defects in one pass were invisible to six hundred unit tests and obvious in a frame, and three of them needed two chambers of history to appear at all. A pooled sprite drawn over a painted one, a caption wider than the thing it labels, and a plate showing through a screen are all correct code producing a wrong picture.
- **Anything with two code paths is proved on both.** `cross-origin-delegation.ts` runs once with the archive origin embedded and once without, because the single-origin fallback has to stay green for as long as `ARCHIVE_ORIGIN` is `same`. A proof of only the path we hope to ship is a proof of the wrong thing.
