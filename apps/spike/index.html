SEMAPHORE · PHASE 0.3 SPIKE

Answers the questions in docs/11-spec-notes.md by exercising the live WebMCP API rather than by reading the specification. Automatic checks run on load. Agent checks stay marked waiting until a model actually calls something.

How to run this

  1. Serve this directory over localhost (a secure context is required): python3 -m http.server 8787 --directory apps/spike
  2. For the cross-origin check, serve a second copy on another port, which is a different origin: python3 -m http.server 8788 --directory apps/spike, then open this page as http://localhost:8787/?archive=http://localhost:8788
  3. Open it in Chrome 149+ with chrome://flags/#enable-webmcp-testing enabled and relaunched, or in the ChatGPT desktop app's in-app browser on GPT-5.6 Sol or Terra (Luna has site tools disabled).
  4. To fill the agent rows, paste this to your agent: "Use the site tools on this page. Call spike_begin, then follow the instructions it returns."
  5. Press Copy report and paste the result into doc 11.
